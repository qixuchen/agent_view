Motivation: Change the Data, Not the Context

Proposal · 1 / 6
Data agents often fail not because they cannot write SQL, but because they misunderstand the data.

Existing: learn knowledge from failuresTK-Boost, MIRA

  • They mine misconceptions from failed tasks and store them as knowledge in text.
  • For every new task, the right piece must be retrieved and applied again.
  • The stored dataset stays unchanged; the fix is injected into the agent's context.

New: generate data artifacts

  • We turn knowledge into a data artifact: a derived view over the original tables.
  • No retrieval needed. The agent's context stays unchanged; what changes is the data it can query.
  • Agents benefit from these views that make the complex task/query simpler.
